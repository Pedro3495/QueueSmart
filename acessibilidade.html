Declaração de Acessibilidade

A equipe do QueueSmart está comprometida em garantir que este sistema seja acessível ao maior número possível de pessoas, independentemente de deficiência, dispositivo ou contexto de uso.

Nível de Conformidade

Este site busca atender ao padrão WCAG 2.2 Nível AA (Web Content Accessibility Guidelines), desenvolvido pelo World Wide Web Consortium (W3C).

Medidas Adotadas

Entre as práticas de acessibilidade implementadas neste projeto, destacam-se:

— Contraste de cores mínimo de 4.5:1 para texto normal;

— Indicação visual e textual de campos obrigatórios;

— Navegação completa via teclado (TAB / SHIFT+TAB);

— Foco visível em todos os elementos interativos;

— Uso de HTML semântico com tags estruturais (header, main, footer);

— Formulários com labels associados a cada campo;

— Linguagem simples e clara em todo o conteúdo.

Limitações Conhecidas

O projeto encontra-se em desenvolvimento ativo. Algumas funcionalidades como mensagens de erro personalizadas e testes com leitores de tela ainda estão em fase de implementação e validação.

Contato e Feedback

Se você encontrar alguma barreira de acessibilidade neste site ou tiver sugestões de melhoria, entre em contato com nossa equipe pelo e-mail: queuesmart@gmail.com
